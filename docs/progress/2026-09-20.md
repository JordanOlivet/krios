- Versioning: SemVer per mod, tags `industry/v0.1.0`; CI via reusable `build-gradle-mod.yml` in JordanOlivet/ci-workflows (cache hygiene + 7-day artifact retention + weekly cache pruning).
- Performance is a founding constraint (ADR-012): tickless idle, batch computation, no hot-path allocation.
- Process: direct pushes to main during bootstrap only; branches + PRs once the base is in place. ci-workflows releases only via PR + VERSION bump once CI shape is final.

## Design settled (docs/mods/01-industry-design.md)

Dual axis: hardware (4 machine tiers + slotted modules) × software (KOIOS levels = unlocks only). KOIOS learns from machine-operation data XP (diversity bonus, anti-AFK); critical levels (items+XP) gate tiers; cores directly craftable as the expensive alternative path. Yield = evolving multiplier on one machine, not a machine chain. Ores: Chronite (hardware axis) + Neurite (software axis). Sober machine naming. Laboratory ruin structures deferred post-MVP.

## Built today (mods/industry)

- **Registration layer**: `IRegistrar` platform service — generic registry + platform-divergent factories (CreativeModeTab builder, BlockEntityType, MenuType). Gotchas hit: vanilla keeps `BlockEntitySupplier`/`MenuType` ctor package-private (loaders widen differently); registries of wildcard generics need cast helpers; `RecipeType.simple` doesn't exist in mojmap.
- **Ores**: chronite/neurite + deepslate variants, silk-touch/fortune loot, worldgen veins (chronite deep −64..0, neurite mid −8..72; features = common datapack JSON, biome injection = neoforge biome_modifier JSON / Fabric BiomeModifications).
- **Generator**: burns furnace fuels (platform `getBurnTime`), 40 E/t, 100k buffer. Tickless idle via LIT blockstate gating the ticker. Energy exposed extract-only: FE capability (NeoForge) + Team Reborn Energy 4.1.0 jar-in-jar with SnapshotParticipant adapter (Fabric).
- **Crusher**: custom datapack recipe type `krios_industry:crushing` (ingredient/result/energy/time), pulls energy from adjacent generators (v0 transport, no cables), WorldlyContainer hopper automation, yield-multiplier hook reserved in `craft()`.
- **Content/recipes**: neurite dust/ingot, `c:` provider tags (ores/raw_materials/dusts/ingots), survival machine recipes (hand-minable only, no chicken-and-egg), ore-block crushing via `c:ores` tags, raw x1-smelt vs x2-crush economy, cobble→gravel→sand.
- **GUI**: menus with ContainerData sync — **values >32767 must ship as low/high 16-bit pairs** (shorts truncation bug found in playtest, fixed).
- Placeholder art: script-generated textures (scratchpad scripts), gear+hourglass mod icon.
- `tools/run-client.bat|.sh [neoforge|fabric] [mod]` for manual play.
