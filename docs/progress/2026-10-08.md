# Progress — 2026-10-08 (Chrono Farmer; ADR-022, ADR-023)

The first line machine of the roadmap (ADR-020) shipped, design to play
test in one session. It lays the zone-machine bricks the Cyclic Forester,
Quantum Lure and creature lines will reuse.

## Design (81a0e49, then revised in play)

- Harvest mature crops in a zone, replant (harvest seeds first), till dirt
  only when a seed can go in right away. t1 scope: the `CropBlock` family
  (torchflower excluded) + nether wart; melon/pumpkin/cane/cocoa deferred
  (user: base of the mod first).
- **Tier brings area**: 9×9 / 13×13 / 19×19 / 27×27 (doubling on area,
  `MachineTiers.zoneEdge`). Modules bring the rest: Speed = forced random
  ticks at the usual ×(2+pts)/2 pace, Yield = whole extra harvests through
  the quarter accumulator, Efficiency = cost. No base yield by tier.
- Reduced KOIOS XP: `FARM_XP_PERMILLE` = 200 (2 XP per harvest, key
  `harvest:<crop>` for diversity).
- **ADR-022** — zone machines pace themselves on scheduled ticks, never a
  ticker. Amended at implementation: the only true stop is a full output
  buffer (starvation would deadlock against paused-full reactors that
  never push; nothing notifies an "empty" zone when the player tills it).
  Shipped: 10 ticks after a wake that acted, 100 otherwise, at most
  4 × speed factor actions per wake.

## Revisions from play (user, same day)

- **Zone behind the screen** (was in front): the screen faces the player
  at placement, so the zone extends where they look — set up from the
  field's edge.
- **Hologram**: corner posts kept inside the footprint (they spilled onto
  neighbor blocks). Shown while the Calibrator is held (48 blocks) and for
  zones pinned from the terminal's eye toggle (client-side, not persisted).
- **Annex stack**: side panels stack per side with a fixed gap whatever
  their neighbors' open/collapsed state, top-aligned with the main frame's
  header (`AnnexPanel.stack`). Vanilla slot coords are final, so the module
  bay heads the left stack (enforced at runtime). Applies to every machine
  terminal — grinder, forge and reactor Mk II now show Modules above Stats.
- **Hydration**: topping moisture up per pass still flickered (vanilla only
  shows moist at 7). **ADR-023**, the codebase's first mixin, makes
  `FarmBlock.isNearWater` answer true inside registered zones
  (`HydrationZones`, in-memory per-level index) — vanilla holds them at 7.
  Rule for future mixins: only when no loader API covers both sides,
  common config, narrowest injection, never an overwrite.
- **Seed routing**: every plantable drop tops up the seed slots first, the
  surplus goes to the buffer; an optional voiding toggle (off by default,
  persisted) destroys the plantable surplus, with a warning sign + tooltip
  while active (carrots/potatoes/wart are destroyed too — the player
  decides, the machine warns).
- **Energy**: buffer aligned on the grinder/forge (8k per tier, was 4k);
  the farmer now also pulls right AFTER its work in the same wake — topping
  up only before working left the gauge drained up to 5 s (sawtooth).
  Pull cap: 400 E per elapsed tick, both pulls combined.
