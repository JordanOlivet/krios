## Responsiveness → ADR-027

Measured before deciding (temporary `/krios_industry bench`, NeoForge
dedicated dev server driven over RCON; dev `server.properties` has RCON
enabled, password `kriosbench`, gitignored). Per node and tick: empty
vanilla ticker 0.085 µs, ticker with machine-like work 0.13–0.14 µs,
scheduled tick every 10 ticks 0.13–0.15 µs (no saving at an active
cadence), one managed loop 0.03–0.056 µs, per-tick `setChanged()` 0.43 µs
(the real trap). User chose **option D** (AE2-like manager), with the
future storage mod in mind.

- `tick/TickManager` per level, hooked on each loader's level tick;
  devices are awake (every tick), sleeping until a game time (probe or
  cadence, one comparison per tick), or asleep (zero cost until an
  alert). Only ticking chunks run, like vanilla.
- Zone machines keep their ADR-022 pacing as device sleeps; LIT machines
  (reactor, grinder, forge, photon) run through `machine/LitDevice` —
  awake while lit, manual item faces probed every 30 ticks, the dark panel
  every 100. `ItemFlow.scheduleWake` became `ItemFlow.alertMachine`. No
  vanilla ticker or scheduled tick remains on machines; `LIT` is visual.
- **Live census** (user): while a player has a creature terminal open, the
  census refreshes every 20 ticks; dead creatures leave the count at once.
  Nobody watching costs nothing.
- `CLAUDE.md` architecture section updated (the old "never a ticker" rule
  was obsolete).
