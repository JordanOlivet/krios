## ADR-020 — machine lines span t1→t4; simulated forms stand beside them (77f1f9c)

- **Reframe (user)**: t1 was the MVP and t2 only validated the t1→t2
  upgrade; neither defines the content model. Every machine is a LINE:
  base version at t1 (nearly every vanilla function gets a basic
  automation there — the solar panel moves to t1), improved each tier
  through the existing upgrade kit and `min(machine tier, core tier)`,
  one interface across t1→t4. A later debut needs a real justification
  (t2 candidates: quarry, magmatic generator — "try it and see").
- **Simulated forms (user concept)**: at t4 the player unlocks BOTH the
  line's t4 machine (fastest, still acting on the world — for players
  who want to watch it happen) AND a separate simulated block: the
  process containerized inside the block (Docker as the reference) and
  run through space-time manipulation at outsized speed and yield.
  Different needs → different interface; informally "t5". The concrete
  meaning of the tier-4 name, Transcendence. Pure computation, the most
  ADR-012-friendly machine there is; energy scales with throughput.
  Generators get an analogous concept, not yet designed.
- **Rules**: network energy only unless stated (generators excepted);
  no feature waits on another content mod (a hopper-throttled quarry
  still ships whole — my earlier storage-dependency framing was wrong,
  it contradicted ADR-018); tool-scale counterparts (handheld
  excavator) belong to a future **Krios: Technologies**, added to the
  VISION ecosystem map.

## The roadmap (industry design doc, new section)

- Lines: Cultivator, Lumberjack, Fisher (rod slot — enchantments apply,
  durability wears), Quarry (X/Z area between Y min/max, items exit at
  the block), Breeder / Collector / Slaughterer (creatures in a zone),
  Spawner "Neural Lure" (default: force-spawn the biome's mobs; imprint
  mode: one creature) + Eliminator (zone damage, upgrades to one-shot),
  Magmatic generator (lava — the explicit fuel exception).
- **Neural imprint**: KOIOS's captured data of a creature — feeds the
  spawner's imprint mode and the creature lines' simulated forms. How
  it is obtained: to design.
- Shared rules: reduced KOIOS XP for self-sufficient processes (one
  permille constant per machine class); zones configured through the
  Calibrator overlay, stopping at unloaded chunks (never force-load);
  blocked output → internal buffer → pause (thermostat model for items).
- Intermediates (microchip, actuator, drill head, condensator,
  supraconductor...) are born with their first consuming machine.
- Kept in mind, not planned: Recycler, villagers (breeding, then
  trading), auto-brewer, composter, fluid infrastructure, the
  generators' simulated analog.
- Names are placeholders: a dedicated naming pass will rename the
  existing plain names (Generator, Crusher...) in the same sweep so two
  registers never coexist.
