## Item transport: shipped (563ce41), rejected in play, withdrawn (e80daee)

- Morning design session settled push triggers, round-robin fairness,
  pull batches (8 × tier speed factor), scheduled wake-ups via vanilla
  scheduled block ticks (**ADR-017** — persisted with chunk saves, zero
  custom infra, never scheduled from chunk load), manual-face-only
  exchange with passive containers, and network-wide batch routing.
- Play verdict (user): **component-wide routing filled any freshly
  placed machine from across the factory** — a new production line
  could not even be set up. Fix iterations (conduit-run scoping, then a
  two-cable split backbone/transport with manual faces at both ends and
  the contact hint) kept drifting into logistics concepts the design
  doc had already fenced off three times as "krios_storage territory".
- The user called the step-back: we were building krios_storage's v0
  inside Industry to avoid starting it. **Withdrawn**: ItemSink,
  Network.offerItems, the ItemFlow network path (−138 lines). Industry
  keeps its LOCAL item behaviors — adjacency flow (restored always-on),
  manual-face chest exchange, the IItemAccess dual adapter (NeoForge
  IItemHandler / Fabric Transfer API), ADR-017 wake-ups, the pull-batch
  knob. The full two-cable design is consigned as **krios_storage's
  opening brief** (design doc, struck flagship bullet).

## Solar panel — complete chantier, play-validated visuals (cee2cf1, 3a0fe07, a32667c)

- **Mechanics (ADR-012/017)**: LIT = producing (day + sky + room);
  only a lit panel ticks. Dark panels poll every ~100 ticks asking
  "can I produce?" — deliberately NO dawn math: scheduled ticks count
  REAL ticks, so `/time set`, bed skips and doDaylightCycle would
  strand a computed wake; the poll self-heals all of them in ≤5 s for
  ~120 checks a night. Rain = half rate, never zero (no weather
  transitions to track; per-position check so deserts stay dry; Mk I
  only — higher tiers will be rain-immune). 8 E/t clear / 4 rain / 0
  night = one panel feeds two induction furnaces in the sun; buffer
  100,000 E (user: produces less, banks more). No KOIOS XP (anti-AFK).
- **Terminal** (user revision at first contact: every block shows its
  state): generator chrome, wide bar, pixel sun colored by state over
  a state label, contextual voice (clear/rain/saturated/sky-blocked),
  energy-out face config with auto-config on contact, no slots (the
  Mk II boost bay is roadmapped). Solar Panel Mk II itself roadmapped.
- **Form** (user): full machine block, cell deck as the top face —
  then a sculpted-relief pass (38 elements): copper risers recessed
  1px into the flanks, the 3x3 cells recessed 0.5px under a raised
  lattice. Three play-iterations fixed: corner-edge z-fighting (edge
  plates must only declare their groove-facing chant), seam shimmer
  between touching panels (cullface on every boundary face), and
  missing groove ceilings/floors. Model validated in play on Fabric.

## Gotchas (hard-won)

- Scheduled block ticks count REAL ticks: never compute a wake-up time
  from day time — beds and /time set strand it. Poll slowly instead.
- Sculpted-model z-fighting rules: an edge plate's boundary-side chant
  is coplanar with the neighbor flank's skin (declare only the
  groove-facing one); every boundary face needs a cullface or touching
  identical blocks shimmer (mirrored UVs); every recess needs its
  ceiling/floor faces or you see through at grazing angles.
- WinPS 5.1 mangles embedded double quotes in args passed to native
  exes (git commit -m with quotes in the message): use `git commit -F
  <file>`. Heredocs don't exist in PowerShell; python scripts go
  through scratchpad files.
- A log-watcher must never watch "the newest file in the tasks dir" —
  it finds its own output file and waits forever.
- **Never launch a dev client — the user launches and drives clients
  themselves** (they pick the loader). Build green + runServer smoke,
  then hand over with a list of what to look at.
- The meta-lesson of the day: when a feature needs repeated "that
  belongs to mod X later" fences, stop patching and raise the
  architecture question — the user wants out of the tunnel, and the
  workaround would be redone properly anyway.
