# Progress — 2026-11-26 (every ore through the grinder)

The user asked to finish the current machines before any new one: the
Fractal Grinder and the Plasma Forge handled chronite and neurite only, and
should double every material of that kind, vanilla or modded (raw iron
ground into two dusts, each smelted into an ingot).

## Materials (ADR-037, pull request #12, merged)

- **Core**: `iron_dust`, `gold_dust`, `copper_dust` (tags `c:dusts/<metal>`
  and the parent `c:dusts`, smelting and blasting into the vanilla ingot,
  recipe advancements, EN and FR names, creative tab). Core also ships
  `c:ores/<vanilla material>` item tags: Fabric API 0.109, which the mods
  build against, has only quartz and netherite scrap.
- **Industry**: 39 grinding recipes. Vanilla metals go ore → raw → 2 dusts;
  vanilla gems and minerals go ore → the item, twice the average drop
  (2 coal, diamond, emerald, quartz; 9 redstone; 13 lapis; 7 raw copper).
  Fifteen metals of other mods (aluminum, antimony, chromium, cobalt,
  iridium, lead, nickel, osmium, platinum, silver, tin, titanium, tungsten,
  uranium, zinc) have an ore and a raw recipe written with **tag results**.
- **`GrindingRecipe`** takes `"result": {"tag": ..., "count": n}`: the
  preferred member of the tag (`TagOutputs`: Krios, vanilla, then the other
  mods by id), resolved at first use and sent resolved to clients. A recipe
  whose tag or ingredient is empty is unavailable: it matches nothing and
  JEI and EMI skip it. No machine code changed.
- **Textures**: three drafts on vanilla redstone dust's shape and shading
  (user call), in each metal's ramp, recorded in `gen_textures.py` (run with
  the three exact names: nothing else was written). The user retouches
  later if needed.
- **Ancient debris** is left out (user call, for the numbers pass).
